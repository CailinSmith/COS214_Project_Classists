\doxysubsection{Detailed Description}
Command for removing a plant from inventory. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates a request to remove a plant from the nursery inventory. It allows staff members to remove plants that are damaged, dead, or no longer needed.
