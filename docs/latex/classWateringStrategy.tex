\doxysubsection{Detailed Description}
Abstract strategy for watering plants. Design Pattern\+: Strategy Participant\+: Strategy. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This abstract class defines the interface for different watering strategies. Concrete implementations (\doxylink{classHighMoisture}{High\+Moisture}, \doxylink{classMediumMoisture}{Medium\+Moisture}, \doxylink{classDryPlant}{Dry\+Plant}) provide specific watering techniques for different plant types. The strategy pattern allows watering behavior to be changed at runtime.
