\doxysubsection{Detailed Description}
Design Pattern\+: Command Participant\+: Concrete Command. 

\begin{DoxyAuthor}{Author}
Abhay Rooplall 
\end{DoxyAuthor}
This class represents a concrete command for processing customer checkout. It encapsulates the checkout request with the customer\textquotesingle{}s order and processes the transaction through the appropriate staff member.
