\doxysubsection{Detailed Description}
Command for fertilising a plant. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates the action of fertilising a plant, allowing staff to apply fertiliser to promote plant growth and health. The command can be executed as part of the nursery\textquotesingle{}s plant care routine.
