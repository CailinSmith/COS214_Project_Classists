\doxysubsection{Detailed Description}
Command for retrieving plant information. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates the action of retrieving detailed information about a plant, including its characteristics, care requirements, and current state. The information can be accessed after execution via the \doxylink{classGetInfoCommand_a91f407df9eb8231f809b4f8f0c12b76e}{get\+Info()} method.
