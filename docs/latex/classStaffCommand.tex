\doxysubsection{Detailed Description}
Abstract base class for staff commands. Design Pattern\+: Command Participant\+: Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class defines the interface for all staff-\/related commands in the nursery system. Concrete command subclasses encapsulate specific staff operations (pruning, watering, checkout, etc.) as objects, allowing for flexible command execution and potential undo/redo functionality.
