\doxysubsection{Detailed Description}
Design Pattern\+: Command Participant\+: Concrete Command. 

\begin{DoxyAuthor}{Author}
Abhay Rooplall 
\end{DoxyAuthor}
Encapsulates a customer\textquotesingle{}s request for plant information into a command object. When executed, routes the information request to appropriate nursery staff who can provide details about plant care, characteristics and maintenance.
