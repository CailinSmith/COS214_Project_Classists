\doxysubsection{Detailed Description}
Implements high moisture watering strategy for plants. Design Pattern\+: Strategy Participant\+: Concrete\+Strategy. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class implements a watering strategy for plants that require frequent watering and consistently moist soil. This strategy is typically used for water-\/loving plants such as certain vegetables, aquatic plants, and tropical species.
