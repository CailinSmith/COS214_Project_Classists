\doxysubsection{Detailed Description}
Represents a fruit-\/bearing plant type in the nursery system. Design Pattern\+: Abstract Factory, Template Method Participant\+: Abstract\+Product (Abstract Factory), Concrete Class (Template Method) 

\begin{DoxyAuthor}{Author}
Cailin Smith 

Jordan Naidoo 
\end{DoxyAuthor}
This class represents fruit-\/producing plants such as trees and vines that bear edible fruits. \doxylink{classFruit}{Fruit} plants typically require specific care and have longer growth periods. This class provides the base cost calculation and seasonal pricing adjustments specific to fruit-\/bearing plants.
