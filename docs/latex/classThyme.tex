\doxysubsection{Detailed Description}
Represents a thyme herb plant. Design Pattern\+: Abstract Factory Participant\+: Concrete\+Product. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class represents thyme, a small aromatic culinary herb with dry plant watering requirements and thinning pruning needs. \doxylink{classThyme}{Thyme} is a drought-\/tolerant Mediterranean herb that requires minimal watering and benefits from regular thinning. Best sold in summer.
