\doxysubsection{Detailed Description}
Command for stocking/restocking the nursery. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates a stocking request as a command object. It allows staff to restock the nursery with new plants or replenish existing inventory.
