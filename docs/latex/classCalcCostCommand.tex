\doxysubsection{Detailed Description}
Command for calculating the cost of a plant. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates the action of calculating the total cost of a plant product, taking into account the current season and any applied decorators. It stores the calculated cost which can be retrieved after execution.
