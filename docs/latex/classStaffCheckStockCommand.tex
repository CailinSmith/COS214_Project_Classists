\doxysubsection{Detailed Description}
Command for checking plant stock levels. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates a stock check request as a command object. It allows staff to query the inventory for the quantity of a specific plant type currently in stock.
