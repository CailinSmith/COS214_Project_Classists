\doxysubsection{Detailed Description}
Concrete factory for creating spring-\/season plants. Design Pattern\+: Abstract Factory Participant\+: Concrete\+Factory. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class implements the \doxylink{classPlantFactory}{Plant\+Factory} interface to create plants that are appropriate for the spring season. Each creation method returns a specific spring plant variety (\doxylink{classRose}{Rose}, \doxylink{classBasil}{Basil}, \doxylink{classTomato}{Tomato}, \doxylink{classLettuce}{Lettuce}, Jade \doxylink{classPlant}{Plant}, Water Lily, Snake \doxylink{classPlant}{Plant}, Aloe Vera).
