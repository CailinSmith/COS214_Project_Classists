\doxysubsection{Detailed Description}
Abstract base class representing a plant product in the nursery system. Design Pattern\+: State, Strategy, Template Method, \doxylink{classDecorator}{Decorator} Participant\+: Context (State), Context (Strategy), Concrete Component (\doxylink{classDecorator}{Decorator}) 

\begin{DoxyAuthor}{Author}
Cailin Smith 

Edwin Kusel 

Jordan Naidoo 
\end{DoxyAuthor}
This class serves as the foundation for all plant types in the nursery management system. It implements the State pattern to manage plant growth states (Seed, Growing, Mature, etc.), and the Strategy pattern for watering and pruning behaviors. Plants track their health, height, water level, and other vital statistics. The class provides both internal management methods and customer-\/facing summary information.
