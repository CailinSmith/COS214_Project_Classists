\doxysubsection{Detailed Description}
Command for making a plant ready for sale. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates the action of preparing a plant for sale by transitioning it to a sellable state and adding it to the inventory manager\textquotesingle{}s sales inventory.
