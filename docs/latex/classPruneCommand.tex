\doxysubsection{Detailed Description}
Command for pruning a plant. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates a pruning request as a command object. It allows staff members to prune a specific plant by delegating the pruning operation to the plant\textquotesingle{}s pruning strategy.
