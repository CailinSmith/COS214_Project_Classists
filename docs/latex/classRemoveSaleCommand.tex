\doxysubsection{Detailed Description}
Command for removing a plant from sale inventory. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates a request to remove a plant from the sellable inventory. It allows staff to take plants off sale that are no longer suitable for purchase or need to be returned to regular inventory.
