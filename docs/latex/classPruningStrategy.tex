\doxysubsection{Detailed Description}
Abstract strategy for pruning plants. Design Pattern\+: Strategy Participant\+: Strategy. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This abstract class defines the interface for different pruning strategies. Concrete implementations (\doxylink{classDeadPruning}{Dead\+Pruning}, \doxylink{classThinning}{Thinning}, \doxylink{classNoPrune}{No\+Prune}) provide specific pruning techniques for different plant types. The strategy pattern allows pruning behavior to be changed at runtime.
