\doxysubsection{Detailed Description}
Represents a purchase receipt for plant products. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class manages a receipt for customer purchases, tracking the products ordered, total cost, and date of purchase. It provides functionality to generate receipt content, remove products, and retrieve receipt information.
