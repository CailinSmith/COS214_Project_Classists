\doxysubsection{Detailed Description}
Command for watering a plant. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates a watering request as a command object. It allows staff members to water a specific plant by delegating the watering operation to the plant\textquotesingle{}s watering strategy.
