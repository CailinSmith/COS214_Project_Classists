\doxysubsection{Detailed Description}
Represents a Peace Lily indoor plant. Design Pattern\+: Abstract Factory Participant\+: Concrete\+Product. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class represents a Peace Lily plant, which is an indoor plant with high moisture watering requirements and dead heading pruning strategy. The plant has a maximum height of 120cm and is available for sale during the \doxylink{classSpring}{Spring} season.
