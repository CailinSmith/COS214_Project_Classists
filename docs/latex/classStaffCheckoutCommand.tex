\doxysubsection{Detailed Description}
Command for processing customer checkout. Design Pattern\+: Command Participant\+: Concrete\+Command. 

\begin{DoxyAuthor}{Author}
Cailin Smith 
\end{DoxyAuthor}
This class encapsulates a checkout request as a command object. It allows staff to process a customer\textquotesingle{}s purchase by creating a receipt for the selected products.
