\doxysubsection{Detailed Description}
Design Pattern\+: \doxylink{classDecorator}{Decorator} Participant\+: Component. 

\begin{DoxyAuthor}{Author}
Jordan Naidoo 
\end{DoxyAuthor}
Defines the common interface for both \doxylink{classPlant}{Plant} objects and \doxylink{classDecorator}{Decorator} objects in the nursery system. This abstract base class allows plants to be decorated with various items such as pots, wrapping and fertilizer while maintaining a uniform interface for cost calculation, naming, and information retrieval.
