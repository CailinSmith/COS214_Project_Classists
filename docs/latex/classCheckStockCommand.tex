\doxysubsection{Detailed Description}
Design Pattern\+: Command Participant\+: Concrete Command. 

\begin{DoxyAuthor}{Author}
Abhay Rooplall 
\end{DoxyAuthor}
This class represents a concrete command for checking plant stock availability. It encapsulates the request to check if a specific plant is in stock, delegating the actual work to the appropriate staff member.
