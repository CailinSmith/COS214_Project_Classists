\doxysubsection{Detailed Description}
Design Pattern\+: \doxylink{classIterator}{Iterator}, Observer Participant\+: Concrete \doxylink{classAggregate}{Aggregate}, Concrete \doxylink{classSubject}{Subject}. 

\begin{DoxyAuthor}{Author}
Alex Lange 

Edwin Kusel 

Jordan Naidoo 

Cailin Smith 
\end{DoxyAuthor}
This class manages the plant inventory for both sale and nursery areas. It implements the \doxylink{classAggregate}{Aggregate} interface to provide iterators for traversing plants by season, and the \doxylink{classSubject}{Subject} interface to notify staff observers when inventory thresholds are reached.
