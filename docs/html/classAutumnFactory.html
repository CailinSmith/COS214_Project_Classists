Detailed Description

Factory for creating autumn-season plants. Design Pattern: Abstract Factory Participant: ConcreteFactory.

Author
Cailin Smith

This class implements the PlantFactory interface to create specific plant types that are available during the Autumn season. It provides factory methods for creating flowers, herbs, fruits, vegetables, succulents, aquatic plants, indoor plants, and medicinal plants suitable for autumn.
