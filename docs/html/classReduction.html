Detailed Description

Concrete pruning strategy for reduction pruning. Design Pattern: Strategy Participant: ConcreteStrategy.

Author
Cailin Smith

This class implements a reduction pruning strategy, which involves cutting back plant growth to control size and shape. This technique is used for plants that need significant trimming to maintain health and appearance.
