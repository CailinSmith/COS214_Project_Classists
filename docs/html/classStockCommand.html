Detailed Description

Command for stocking/restocking the nursery. Design Pattern: Command Participant: ConcreteCommand.

Author
Cailin Smith

This class encapsulates a stocking request as a command object. It allows staff to restock the nursery with new plants or replenish existing inventory.
