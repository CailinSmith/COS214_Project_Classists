Detailed Description

Design Pattern: Chain of Responsibility Participant: Concrete Handler.

Author
Abhay Rooplall
Edwin Kusel

This class represents sales staff members who handle customer checkout and refund requests. It implements the Staff interface as part of the Chain of Responsibility pattern, processing sales-related requests.
