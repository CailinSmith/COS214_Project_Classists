Detailed Description

Concrete factory for creating spring-season plants. Design Pattern: Abstract Factory Participant: ConcreteFactory.

Author
Cailin Smith

This class implements the PlantFactory interface to create plants that are appropriate for the spring season. Each creation method returns a specific spring plant variety (Rose, Basil, Tomato, Lettuce, Jade Plant, Water Lily, Snake Plant, Aloe Vera).
