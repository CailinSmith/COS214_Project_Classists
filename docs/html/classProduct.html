Detailed Description

Design Pattern: Decorator Participant: Component.

Author
Jordan Naidoo

Defines the common interface for both Plant objects and Decorator objects in the nursery system. This abstract base class allows plants to be decorated with various items such as pots, wrapping and fertilizer while maintaining a uniform interface for cost calculation, naming, and information retrieval.
