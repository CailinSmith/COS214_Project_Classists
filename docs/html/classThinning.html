Detailed Description

Concrete pruning strategy for thinning. Design Pattern: Strategy Participant: ConcreteStrategy.

Author
Cailin Smith

This class implements a thinning pruning strategy, which involves selectively removing branches, stems, or foliage to improve air circulation and light penetration. This technique helps promote healthier growth and better plant structure.
