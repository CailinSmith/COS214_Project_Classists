Detailed Description

Abstract strategy for pruning plants. Design Pattern: Strategy Participant: Strategy.

Author
Cailin Smith

This abstract class defines the interface for different pruning strategies. Concrete implementations (DeadPruning, Thinning, NoPrune) provide specific pruning techniques for different plant types. The strategy pattern allows pruning behavior to be changed at runtime.
