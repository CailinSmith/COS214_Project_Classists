Detailed Description

Design Pattern: Iterator Participant: Concrete Iterator.

Author
Alex Lange

This class implements the Iterator pattern to provide sequential access to Plant objects that match a specific season. It filters plants from a collection and allows iteration over only those plants that are associated with the target season.
