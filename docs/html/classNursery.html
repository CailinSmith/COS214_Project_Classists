Detailed Description

Central management system for the nursery operations. Design Pattern: Singleton, State Participant: Singleton, Context (State Pattern)

Author
Cailin Smith
Edwin Kusel

This class serves as the central control system for the nursery, managing the current season state, plant factory, and inventory. It implements the Singleton pattern to ensure only one nursery instance exists, and acts as the Context in the State pattern for managing seasonal changes. The nursery coordinates season transitions, plant production, and inventory management.

Usage: First initialize: InventoryManager* inventoryManager = new InventoryManager(); Nursery* nursery = Nursery::getInstance(inventoryManager);

To access inventory manager: InventoryManager* im = nursery->getInventoryManager();

To access the singleton: Nursery* n = Nursery::getInstance();
