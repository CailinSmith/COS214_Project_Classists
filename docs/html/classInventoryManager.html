Detailed Description

Design Pattern: Iterator, Observer Participant: Concrete Aggregate, Concrete Subject.

Author
Alex Lange
Edwin Kusel
Jordan Naidoo
Cailin Smith

This class manages the plant inventory for both sale and nursery areas. It implements the Aggregate interface to provide iterators for traversing plants by season, and the Subject interface to notify staff observers when inventory thresholds are reached.
