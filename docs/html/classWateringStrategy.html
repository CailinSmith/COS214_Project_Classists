Detailed Description

Abstract strategy for watering plants. Design Pattern: Strategy Participant: Strategy.

Author
Cailin Smith

This abstract class defines the interface for different watering strategies. Concrete implementations (HighMoisture, MediumMoisture, DryPlant) provide specific watering techniques for different plant types. The strategy pattern allows watering behavior to be changed at runtime.
